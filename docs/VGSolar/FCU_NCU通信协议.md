## 一、名词与链路

| 名称 | 标识 | 角色 |
|------|------|------|
| NCU | `0xAA` | 导引单元，发运动/参数/系统/导航指令 |
| FCU | `0xBB` | 车控飞控，执行并上报状态 |

| 项目 | 值 |
|------|-----|
| 物理接口 | UART，TTL，3 线 |
| 波特率 | **115200**，8N1 |
| 典型映射 | MCU `USART3` → ArduPilot `SERIAL6`，`PROTOCOL=50`（地面站 `CC_*` / `SERIAL6_*` 见 [地面站参数配置.md](./地面站参数配置.md)） |

多字节字段均为 **小端序（little-endian）**。

---

## 二、通用帧格式

| 偏移 | 长度 | 含义 | 值 |
|------|------|------|-----|
| 0~1 | 2 | 起始码 | `0xA5 0x5A` |
| 2 | 1 | 指令来源 | `0xAA` NCU / `0xBB` FCU |
| 3 | 1 | 指令类型 | 见下文 |
| 4 | 1 | 数据长度 N | 数据体字节数 |
| 5 .. 4+N | N | 数据体 | — |
| 5+N | 1 | 校验和 | 见下 |
| 6+N | 1 | 结束位 | `0xFF` |

**整帧长度** = N + 7。

**校验和**：从「指令来源」（byte2）起，到「数据体最后一个字节」止，各字节 `uint8` 累加后对 256 取模。**帧头 `0xA5 0x5A` 不参与**。

**收包超时**：单帧接收过程建议 ≤ 200 ms（实现常量 `PACKET_TIMEOUT_MS`）。

## 三、指令总览

### 3.1 NCU → FCU

| 类型 | 名称 | 数据长度 | 发送方式 | FCU 应答 |
|------|------|----------|----------|----------|
| `0x01` | 速度控制 | 5 | 按需（运动中持续；零速一次即可） | **无**单独 ACK；靠状态反馈 |
| `0x02` | 转弯 | 6 | 按需 | 立即 `0xBB 0x02`（仅表示已接收） |
| `0x03` | 参数设置 | 7 | 按需 | `0xBB 0x02`；成功时再发 `0xBB 0x03` |
| `0x04` | 参数读取 | 2 | 按需 | `0xBB 0x03`（未知索引可不发 ACK） |
| `0x05` | 系统控制 | 1 | 按需 | 立即 `0xBB 0x02`，再执行动作 |
| `0x06` | 位置控制 | 15 | 按需 | 立即 `0xBB 0x02`；导航中另发 `0xBB 0x04` |

### 3.2 FCU → NCU

| 类型 | 名称 | 数据长度 | 发送方式 |
|------|------|----------|----------|
| `0x01` | 状态反馈 | **34** | **10 Hz**（含四路超声波 cm） |
| `0x02` | 指令执行反馈 | 2 | 按需 |
| `0x03` | 参数反馈 | 7 | 按需 |
| `0x04` | 导航状态反馈 | 8 | 导航激活期间约 10 Hz |

## 四、NCU → FCU 指令详解

### 4.1 速度控制 `0x01`

| 字段 | 类型 | 含义 |
|------|------|------|
| 控制模式 | uint8 | `0x01` yaw；`0x02` yawrate |
| 线速度 | int16 | cm/s，-500~500，正=前进 |
| 偏航数据 | int16 | yaw：0~36000（0.01°，正北 0、顺时针）；yawrate：-18000~18000（0.01°/s，**正=左转**） |

**FCU 行为**：跟踪最新速度帧。不单独 ACK。状态反馈中 `control_mode` 反映 yaw / yawrate。非零速度打开约 200 ms 丢控看门狗；零速关闭看门狗。

**优先级**：低于系统控制、转弯、位置导航（实现侧：系统 > 转弯 > 导航 > 速度）。

### 4.2 转弯 `0x02`

| 字段 | 类型 | 含义 |
|------|------|------|
| 转弯模式 | uint8 | `0x01` 原地差速；`0x02` 行进间 |
| 转弯方向 | uint8 | `0x01` 左；`0x02` 右 |
| 目标转弯角度 | uint16 | 相对角，0.01°，最大 360° |
| 转弯角速度 | uint16 | 0.01°/s |

**FCU 内部序列**（NCU 只发一条指令）：

```
停车 → 等停稳 → 放吸盘吸附 → 差速/行进转弯（累计航向）→ 抬吸盘 → 恢复转弯前控制模式
```

- 立即回 `0xBB 0x02` = **已接收**，≠ 转弯完成。  
- 完成与否由 NCU 看状态反馈的 `control_mode` / `motion_state` / `fault_code` 及超时。  
- **吸盘无独立协议**，完全由 FCU 转弯状态机驱动（见吸盘行为说明）。

**状态上报约定**

| 字段 | 转弯期间 | 差速转动段 |
|------|----------|------------|
| `control_mode` | 全程 `0x03` | `0x03` |
| `motion_state` | 停车/放吸盘/抬吸盘多为 `0x00` | 已吸附且未冻结时为 **`0x03`** |

二者不同步是正常的：`control_mode` 表示「在执行转弯任务」，`motion_state=0x03` 表示「处于协议定义的差速转弯段」。

### 4.3 参数设置 `0x03` / 读取 `0x04`

| 字段 | 设置 | 读取 |
|------|------|------|
| 参数索引 | uint16 | uint16 |
| 参数类型 | uint8：`0x01` int32 / `0x02` float32 / `0x03` uint32 | — |
| 参数值 | 4 字节小端 | — |

**当前已实现的运行参数（不落盘）**

| 索引 | 类型 | 含义 | 值域 |
|------|------|------|------|
| `0x0101` | uint32 | 前滚刷开关 | 0/1 |
| `0x0102` | uint32 | 后滚刷开关 | 0/1 |
| `0x0103` | uint32 | 前后同时开关 | 0/1 |
| `0x0104` | uint32 | 滚刷功率 | 0~100 |

其它索引对接 `AP_Param` 仍为扩展项。仅写功率、未开刷时可不输出 PWM（需开刷参数后生效）。

**应答**

- 设置成功：`0xBB 0x02` 成功 + `0xBB 0x03` 回传当前值  
- 设置失败：仅 `0xBB 0x02` 失败  
- 读取：回 `0xBB 0x03`；未知索引可不发 ACK

### 4.4 系统控制 `0x05`

| 值 | 含义 | 实现要点 |
|----|------|----------|
| `0x01` | 急停 | 停车、关刷、吸盘释放；`motion_state=0x04` |
| `0x02` | 解除急停 | 回待机；可再尝试安全恢复 |
| `0x03` | 重启 FCU | 先急停再软件复位 |
| `0x04` | 关机 | **当前未实现**（需确认 GPIO 保持逻辑） |

收到后先 ACK，再执行。

### 4.5 位置控制 `0x06`

| 字段 | 类型 | 含义 |
|------|------|------|
| 导航模式 | uint8 | `0x01` GPS；`0x02` NED；`0x03` Body；`0x04` 取消 |
| 目标 X | int32 | GPS：经度×1e7；NED：北向 cm；Body：前方 cm |
| 目标 Y | int32 | GPS：纬度×1e7；NED：东向 cm；Body：右侧 cm |
| 到达航向 | uint16 | 0.01°；`0xFFFF` = 不指定 |
| 到达半径 | uint16 | cm；0 可用默认航点半径 |
| 巡航速度 | int16 | cm/s；0=默认；负=倒车接近 |

取消导航时其余字段填 0，帧长不变。导航过程中 FCU 发 `0xBB 0x04`。

## 五、FCU → NCU 反馈详解

### 5.1 状态反馈 `0x01`（10 Hz，必保）

数据体长度 **34 字节**（`0x22`）。小端序。

| 字段 | 类型 | 含义 |
|------|------|------|
| 车辆电量 | uint8 | % |
| 经度 / 纬度 | int32 | 度×1e7 |
| 航向 | uint16 | 0.01°，正北 0、顺时针 |
| 线速度 | int16 | 地速 cm/s |
| 左 / 右履带速度 | int16 | cm/s（轮速计） |
| 横滚 / 俯仰 | int16 | 0.01° |
| 控制模式 | uint8 | 见 5.1.1 |
| 运动状态 | uint8 | 见 5.1.2 |
| 故障码 | uint16 | 见第六节 |
| GPS 状态 | uint8 | `0` 无 / `1` 2D / `2` 3D / `3` RTK |
| 左外距离 LEFT_OUT | uint16 | cm；接传感器；无效 **`0xFFFF`** |
| 左内距离 LEFT_IN | uint16 | cm；当前拷贝 LEFT_OUT |
| 右内距离 RIGHT_IN | uint16 | cm；当前拷贝 RIGHT_OUT |
| 右外距离 RIGHT_OUT | uint16 | cm；接传感器；无效 **`0xFFFF`** |

**超声波约定**：

- 四路均在车头；顺序 `LEFT_OUT → LEFT_IN → RIGHT_IN → RIGHT_OUT`。
- 板载仅两路串口：LEFT_OUT / RIGHT_OUT 读 `RangeFinder`（Good 时为真实 cm）；LEFT_IN / RIGHT_IN 同侧拷贝。
- 未配置/超时/非 Good → 对应侧为 `0xFFFF`（内侧一并拷贝）。
- 状态帧仍报真实距离；安全带急停由 Mode 侧 `VGS_RF_MIN`/`RF_MAX` 处理。
- 地面站 `RNGFNDx_ORIENT`：LEFT_OUT=`7`(YAW_315)、RIGHT_OUT=`1`(YAW_45)。

#### 5.1.1 控制模式 `control_mode`

| 值 | 含义 |
|----|------|
| `0x00` | 待机 |
| `0x01` | yaw |
| `0x02` | yawrate |
| `0x03` | 转弯任务中 |
| `0x04` | 位置导航（GPS/NED） |
| `0x05` | 位置导航（Body） |

非 VGSL 模式时实现上常报待机。

#### 5.1.2 运动状态 `motion_state`

| 值 | 含义 | 何时 |
|----|------|------|
| `0x00` | 静止 | 履带无有效运动 |
| `0x01` | 前进 | 线速度 > 0 |
| `0x02` | 后退 | 线速度 < 0 |
| `0x03` | 转弯中 | 已吸附差速转，且非冻结 |
| `0x04` | 急停 | 急停有效且未因故障覆盖 |
| `0x05` | 故障 | 故障码命中运动相关 mask（实现上故障优先于急停显示） |

### 5.2 指令执行反馈 `0x02`

| 字段 | 类型 | 含义 |
|------|------|------|
| 收到的指令类型 | uint8 | 对应 NCU `0x01`~`0x06` |
| 执行状态 | uint8 | `0x01` 成功；`0x02` 失败 |

### 5.3 参数反馈 `0x03`

与参数设置体同结构：索引 + 类型 + 4 字节值。

### 5.4 导航状态反馈 `0x04`

| 字段 | 类型 | 含义 |
|------|------|------|
| 导航状态 | uint8 | `0x00` 空闲；`0x01` 导航中；`0x02` 已到达；`0x03` 失败；`0x04` 已取消 |
| 当前坐标模式 | uint8 | `0x01` GPS；`0x02` NED；`0x03` Body |
| 距目标距离 | uint32 | cm |
| 航向偏差 | int16 | 0.01°，正=目标在左侧 |

空闲时可不发送本帧。

## 六、故障码（16 bit）

| Bit | 含义 | 备注 |
|-----|------|------|
| 0 | 左电机 / 左轮速异常 | |
| 1 | 右电机 / 右轮速异常 | |
| 2 | 前滚刷故障 | 扩展 |
| 3 | 后滚刷故障 | 扩展 |
| 4 | 吸盘故障 | 吸附/释放超时等 |
| 5 | IMU 故障 | |
| 6 | GPS 无信号 | |
| 7 | （预留）原 NCU 通信超时 | **不再置位**；运动中丢控仅停车不上报故障 |
| 8 | 低电压 | 如电量 ≤ 20% 阈值 |
| 9 | 倾角过大 | 已吸附场景会 freeze |
| 10 | 转弯或导航失败 | |
| 11 | 超声波安全带 | LEFT_OUT/RIGHT_OUT 超 `VGS_RF_MIN~MAX` 或无效；伴随 ESTOP |
| 12~15 | 预留 | |

多故障按位或；无故障为 0。

**运动丢控看门狗（实现）**：仅在收到**非零速度**后启动；约 200 ms 无新速度帧则停车/关刷，**不置 bit7**。零速、系统控制、TURN/NAV 不打开该看门狗；静默为常态。

**2BLD6010 遥测边界**：当前 `AP_ESC_Telem_2BLD6010` 是独立只读监控后端。它读取的设备故障码、RPM、电压、电流和温度尚未写入本协议的状态反馈；bit0~bit3 也不会因 `BESC` 日志中的 `Fault` 非零而自动置位。若后续要求 NCU 接收电调遥测或将电调故障接入安全策略，必须先定义新的协议字段/指令或明确现有 fault bit 的映射规则，再同步修改飞控与本文档。

## 七、协作时序（摘要）

### 7.1 常态

```
NCU ──速度 10Hz──► FCU
NCU ──转弯/导航/参数/系统──► FCU ──0xBB 0x02/0x03──► NCU
NCU ◄──状态 10Hz── FCU
NCU ◄──导航状态 10Hz── FCU（仅导航中）
```

### 7.2 转弯

```
NCU: 0x02 转弯
FCU: 立即 0xBB 0x02
FCU: control_mode=0x03 → 停车 → 吸盘放下 → 差速转(motion_state=0x03) → 抬起 → 恢复模式
NCU: 观察状态帧退出转弯且 fault 无 bit4 后继续任务
```

### 7.3 滚刷

```
NCU: 0x03 写 0x0104=功率 → FCU ACK + 参数回传
NCU: 0x03 写 0x0103=1 → 开刷
NCU: 0x03 写 0x0103=0 → 关刷
```

## 八、安全与互斥（飞控兜底）

| 场景 | FCU 行为 |
|------|----------|
| 运动中丢控（非零速度后约 200 ms 无新速度帧） | 停车、关刷；已吸附则 freeze；**不置 bit7** |
| 急停 | 停车、关刷、吸盘释放；拒绝速度类运动直至解除 |
| 超声波安全带 | LEFT_OUT/RIGHT_OUT 超 `VGS_RF_MIN~MAX` 或无效 → 同急停 + fault bit11；需解除急停 |
| 低电压 | 关刷、拒绝开刷参数；bit8 |
| 倾角过大（已吸附） | 停车、freeze 保压；bit9 |
| 吸盘 FAULT | 中止转弯、bit4 |
| 未解锁 | 拒绝吸附/开刷等外设动作，强制安全位 |
| 转弯 vs 导航 | 不可并发；滚刷参数可在安全条件下独立生效 |
