# VGSolar 吸盘行为说明

本文说明吸盘在 **VGSL（模式 17）** 下的对外行为：何时放下/抬起、如何判定到位、安全保持与故障。  
参数表见 [地面站参数配置.md](./地面站参数配置.md)；引脚见 [STM32H743VIT6的IO资源分配.md](./STM32H743VIT6的IO资源分配.md)；NCU 通信见 [FCU_NCU通信协议.md](./FCU_NCU通信协议.md)。  
库内 API / 相位枚举 / 协议字段细节见 `libraries/AP_SuctionCup/README.md`。

---

## 一、硬件与输出

| 部件 | 控制方式 | 要点 |
|------|----------|------|
| 升降舵机 | SERVO FUNCTION **159** | PWM 目标可调；按 `SCUP_LIFT_RATE` **缓速**到位 |
| 气阀 | Relay（默认 RELAY1 / GPIO59） | ON=密封，OFF=放气 |
| 气泵 | Relay（默认 RELAY2 / GPIO60） | ON=开泵，OFF=关泵；建负压后会关泵保压 |
| 到位红外 | GPIO（默认 **98**） | 槽型光电 + 铁片；`SCUP_IR_PIN=-1` 则仅用延时 |

NCU **无**吸盘专用指令：吸附/释放由转弯序列在 FCU 内触发。

---

## 二、谁在什么时候动吸盘

| 场景 | 行为 |
|------|------|
| 进入 VGSL | 清故障 → 激活吸盘库（默认抬起空闲） |
| 退出 VGSL / 急停 | 完整释放（关泵、放气、抬起） |
| 转弯 `LOWER_SUCTION` | `lower()`，等到吸附完成 |
| 转弯差速段 | 保持 **关泵 + 密封 + 放下** |
| 转弯 `RAISE_SUCTION` | `raise()`，等到抬起完成 |
| 未解锁 / 中途 disarm | 拒绝新的 `lower()`；强制释放到安全位 |
| 倾角过大 / NCU 断连 | `freeze()`：停序列，已吸附则 **不抬起、保持密封** |

进 VGSL **不要求**先解锁；未解锁时可进模式，但外设保持安全位，解锁后才允许吸附等动作。

## 三、吸附与释放时序

### 3.1 吸附 `lower()`

```
放气 + 停泵 → 缓速放下 → 等到位 → 密封 → 开泵 → 等 VAC_DLY → LOWERED（随后关泵保压）
```

**到位判定**

| 条件 | 判定 |
|------|------|
| 有红外 | 缓速中可记「见过铁片」；PWM 到位后再等「无铁片」（完全放下）。超时 → FAULT，**不密封、不开泵** |
| 无红外 | PWM 到位后再等 `SCUP_LIFT_DLY_MS` |

「先见有、再等无」是为了避免断线/下拉一直读「无」时立刻开泵。

### 3.2 释放 `raise()`

```
关泵 → 放气 → 等 VENT_DLY → 缓速抬起 → 等到位 → RAISED
```

**到位判定**

| 条件 | 判定 |
|------|------|
| 有红外 | 见铁片后等 `LIFT_DLY`（见过后抖动不重计时），且 PWM 须到位 |
| 无红外 | PWM 到位后再等 `LIFT_DLY` |

### 3.3 转弯总流程（Mode）

```
停车 → 等停稳 → 吸附 → 差速转 → 释放 → 结束
```

转弯超时（`VGS_TURN_TO`）**不置**吸盘故障位：已吸附则尝试抬起，未吸附则直接结束转弯。

## 四、安全保持与恢复

| 触发 | 吸盘动作 | 恢复后 |
|------|----------|--------|
| 已吸附且倾角过大（约 >30°） | `freeze()`，保持密封 | 倾角回限 → 解除冻结并 **抬起** |
| 运动丢控（非零速度后约 200 ms 无新速度帧）且已吸附 | 停车、关刷、`freeze()`；不报 bit7 | 再收到 NCU 指令且倾角正常 → 解除并抬起 |
| 急停 | `emergency_release()` 完整释放 | 解除急停后回待机，再视情况恢复 |

冻结期间 **不主动抬起**（防掉落）。若冻结发生在吸附未完成，解除后回到抬起空闲，而不是「已吸附」。

---

## 五、故障（fault bit4）

常见触发：

- `SCUP_ACT_TOUT_MS`：整段 lower/raise 超时  
- `SCUP_LIFT_TO_MS`：有红外时等放下/见铁片超时

进入 FAULT 后：停泵放气；转弯会中止并上报 bit4。  
清除：重新进入 VGSL（`_enter` 时 `clear_fault()`），或由地面站侧清故障流程。

---

## 六、实机注意

参数默认值与推荐配置见 [地面站参数配置.md](./地面站参数配置.md)。

- 红外极性 `IR_POL` 须实机标定；无传感器设 `IR_PIN=-1`。  
- 负压目前仅靠延时，无压力传感器。  
- `ACT_TOUT` 须覆盖缓速 + 到位判定 + 建负压（或放气抬起）最坏耗时。  
- 已保存旧参数的飞控不会自动更新升降默认 PWM。
