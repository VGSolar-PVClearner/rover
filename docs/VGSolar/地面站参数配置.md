# VGSolar 地面站参数配置

面向 Mission Planner / QGroundControl 的 VGSolar 机型参数清单。引脚与 MCU 外设对照见同目录 [STM32H743VIT6的IO资源分配.md](./STM32H743VIT6的IO资源分配.md)。吸盘状态机细节见 `libraries/AP_SuctionCup/README.md`。

> **说明**  
> - 参数名以飞控当前固件为准；改完后写入（Write）、必要时重启。  
> - `SERVOx` 通道号取决于板级 `PWM` 接线，下表「典型通道」按当前 IO 文档推荐；若板子改线，只改通道号，**FUNCTION 数值不变**。  
> - 未解锁时滚刷/气阀/气泵/吸盘会保持安全位；调试外设前需先完成解锁预检。

---

## 一、首次上电必配（清单）

按顺序配置并确认：

1. **模式**：`VGS_ENABLE=1`，飞行模式中某一档设为 **VGSolar（模式 17）**
2. **NCU 串口**：`SERIAL6_PROTOCOL=50`，`SERIAL6_BAUD=115`，`CC_ENABLE=1`，`CC_PORT=0`
3. **履带 / 滚刷 / 升降 SERVO FUNCTION**（见第二节）
4. **气阀 / 气泵 Relay**（见第三节）
5. **吸盘红外**（可选）：默认 `SCUP_IR_PIN=98`；无传感器时设 `-1`

---

## 二、SERVO 输出（FUNCTION）

| 功能 | 典型通道 | `SERVOx_FUNCTION` | 说明 |
|------|----------|-------------------|------|
| 左履带 | SERVO1 | **73** | ThrottleLeft |
| 右履带 | SERVO3 | **74** | ThrottleRight |
| 前滚刷 | SERVO2 | **157** | VGSolarBrushFront |
| 后滚刷 | SERVO4 | **158** | VGSolarBrushRear |
| 吸盘升降 | SERVO5 | **159** | VGSolarSuctionLift |

滚刷由 NCU 经 `AP_CompanionComputer` 写功率；电调约定 **1000 µs=停 / 2000 µs=满速**。  
升降目标 PWM 由 `SCUP_LIFT_PWM_R` / `SCUP_LIFT_PWM_L` 决定，并按 `SCUP_LIFT_RATE` 缓变。

旧版气阀/气泵 PWM（FUNCTION **160/161**）已废弃，勿再占用。

---

## 三、气阀 / 气泵（Relay）

| 参数 | 推荐值 | 含义 |
|------|--------|------|
| `RELAY1_FUNCTION` | **1** | Relay |
| `RELAY1_PIN` | **59** | 气阀 GPIO（PE5） |
| `RELAY1_DEFAULT` | **0** | 上电默认关 |
| `RELAY2_FUNCTION` | **1** | Relay |
| `RELAY2_PIN` | **60** | 气泵 GPIO（PE6） |
| `RELAY2_DEFAULT` | **0** | 上电默认关 |
| `SCUP_VLV_RLY` | **0** | 吸盘库使用 RELAY1 |
| `SCUP_PUMP_RLY` | **1** | 吸盘库使用 RELAY2 |

逻辑：Relay **ON** = 阀密封 / 泵开；**OFF** = 放气 / 泵关。若硬件低有效，设对应 `RELAYx_INVERTED=1`。

---

## 四、串口与伴生电脑（NCU）

| 用途 | 参数 | 推荐值 |
|------|------|--------|
| 数传 | `SERIAL2_PROTOCOL` | **2**（MAVLink2） |
| 遥控器 | `SERIAL1_PROTOCOL` | **23** |
| 超声波 1 | `SERIAL4_PROTOCOL` / `SERIAL4_BAUD` | **9** / **9**（9600） |
| 超声波 2 | `SERIAL5_PROTOCOL` / `SERIAL5_BAUD` | **9** / **9** |
| **RK3588 / NCU** | `SERIAL6_PROTOCOL` / `SERIAL6_BAUD` | **50** / **115**（115200） |
| GPS | `SERIAL7_PROTOCOL` | **5** |
| 电调遥测 | `SERIAL8_PROTOCOL` / `SERIAL8_BAUD` | **51** / **115** |

| 参数 | 默认 | 含义 |
|------|------|------|
| `CC_ENABLE` | **0** → 实机改 **1** | 启用伴生电脑协议 |
| `CC_PORT` | **0** | 第 N 个「协议 50」串口实例（仅配 SERIAL6 时为 0） |

MCU 外设名（如 USART3）≠ `SERIALn` 编号，以 IO 分配文档为准。

## 五、VGSL 模式参数（`VGS_`）

| 参数 | 默认 | 范围 | 含义 |
|------|------|------|------|
| `VGS_ENABLE` | **0** | 0/1 | 启用 VGSolar 模式（须为 1） |
| `VGS_KP_YAW` | **1.0** | 0.1~10 | 航向 P |
| `VGS_KP_SPEED` | **0.5** | 0.1~5 | 速度 P |
| `VGS_CRUISE_SPD` | **1.0** | 0.1~5 | 默认巡航速度 m/s |
| `VGS_TURN_TO` | **15** | 5~60 | 转弯整段超时 s（超时不置吸盘 bit4） |
| `VGS_TURN_SPD` | **0.3** | 0.1~1 | 转弯最大线速度 m/s |

## 六、吸盘参数（`SCUP_`）

| 参数 | 默认 | 范围 | 含义 |
|------|------|------|------|
| `SCUP_LIFT_DLY_MS` | **2000** | 0~5000 | 无红外：PWM 到位后等待；有红外抬起：见铁片后补行程 |
| `SCUP_VAC_DLY_MS` | **3000** | 100~10000 | 开泵后建负压等待 |
| `SCUP_VENT_DLY_MS` | **2000** | 100~5000 | 放气后、抬起前等待 |
| `SCUP_ACT_TOUT_MS` | **30000** | 1000~60000 | lower/raise 整段超时 → FAULT |
| `SCUP_LIFT_PWM_R` | **1900** | 1000~2000 | 抬起位置 PWM µs |
| `SCUP_LIFT_PWM_L` | **1100** | 1000~2000 | 放下位置 PWM µs |
| `SCUP_LIFT_RATE` | **400** | 50~5000 | 升降缓变 µs/s（默认约 2 s 走完 800 µs） |
| `SCUP_VLV_RLY` | **0** | 0~5 | 气阀 Relay 实例 |
| `SCUP_PUMP_RLY` | **1** | 0~5 | 气泵 Relay 实例 |
| `SCUP_IR_PIN` | **98** | ≥0 或 -1 | 槽型光电 GPIO；**-1=禁用红外** |
| `SCUP_IR_POL` | **0** | 0/1 | 0：高=有铁片、低=完全放下；1：反相 |
| `SCUP_IR_DEB_MS` | **30** | 0~500 | 红外消抖 ms |
| `SCUP_LIFT_TOUT_MS` | **5000** | 500~15000 | 有红外时等放下/见铁片超时 → FAULT |

**到位逻辑摘要**

- 有红外：放下 = 缓速中可记「见过铁片」，PWM 到位后再等「无铁片」；抬起 = 见铁片 + `LIFT_DLY`，且 PWM 到位。  
- 无红外（`IR_PIN=-1`）：PWM 到位后再等 `LIFT_DLY`。  
- 已保存旧参数的飞控不会自动改升降默认值，需手动设 `LIFT_PWM_R/L` 或重置相关参数。

## 七、其它常用项

| 类别 | 参数提示 |
|------|----------|
| 轮速计 | `WENC_PINA/B`、`WENC2_PINA/B`（见 IO 文档） |
| 测距 | `RNGFND1_TYPE=45`、`RNGFND2_TYPE=45`（与超声波串口配合） |

| 罗盘/气压 | 板载探测；按机身方向校准 `COMPASS*` |

## 八、快速粘贴块（VGSolar 推荐基线）

按需粘贴到参数表（通道号按实机核对）：

```text
VGS_ENABLE = 1
CC_ENABLE = 1
CC_PORT = 0

SERIAL6_PROTOCOL = 50
SERIAL6_BAUD = 115

SERVO1_FUNCTION = 73
SERVO2_FUNCTION = 157
SERVO3_FUNCTION = 74
SERVO4_FUNCTION = 158
SERVO5_FUNCTION = 159

RELAY1_FUNCTION = 1
RELAY1_PIN = 59
RELAY1_DEFAULT = 0
RELAY2_FUNCTION = 1
RELAY2_PIN = 60
RELAY2_DEFAULT = 0

SCUP_VLV_RLY = 0
SCUP_PUMP_RLY = 1
SCUP_IR_PIN = 98
```

无红外传感器时：`SCUP_IR_PIN = -1`。
