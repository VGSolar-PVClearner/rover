# VGSolar 地面站参数配置

面向 Mission Planner / QGroundControl 的 VGSolar 机型参数清单。引脚与 MCU 外设对照见同目录 [STM32H743VIT6的IO资源分配.md](./STM32H743VIT6的IO资源分配.md)。吸盘状态机细节见 [吸盘行为说明.md](./吸盘行为说明.md)，压力模块说明见 [AP_SuctionPressure_开发过程.md](./AP_SuctionPressure_开发过程.md)，2BLD6010 电调遥测实现见 [AP_ESC_2BLD6010_开发过程.md](./AP_ESC_2BLD6010_开发过程.md)。

> **说明**  
> - 参数名以飞控当前固件为准；改完后写入（Write）、必要时重启。  
> - `SERVOx` 通道号取决于板级 `PWM` 接线，下表「典型通道」按当前 IO 文档推荐；若板子改线，只改通道号，**FUNCTION 数值不变**。  
> - 未解锁时滚刷/气阀/气泵/吸盘会保持安全位；调试外设前需先完成解锁预检。
> - VGSolar 的 PC0 已用于吸盘压力输入，`SPRESS_PIN=10`；不得再配置为 `BATT2_CURR_PIN=10`。
> - `AP_ESC_Telem_2BLD6010` 当前仅通过 Modbus RTU **读取遥测**，不会经 RS485 下发启停、转速或方向命令；履带和滚刷控制仍走 `SERVOx_FUNCTION` 对应的 PWM 输出。

---

## 一、首次上电必配（清单）

按顺序配置并确认：

1. **模式**：`VGS_ENABLE=1`，飞行模式中某一档设为 **VGSolar（模式 17）**
2. **NCU 串口**：`SERIAL6_PROTOCOL=50`，`SERIAL6_BAUD=115`，`CC_ENABLE=1`，`CC_PORT=0`
3. **履带 / 滚刷 / 升降 SERVO FUNCTION**（见第二节）
4. **气阀 / 气泵 Relay**（见第三节）
5. **吸盘红外**（可选）：默认 `SCUP_IR_PIN=98`；无传感器时设 `-1`
6. **吸盘压力**：确认 `SPRESS_PIN=10`，并检查 `SUCT_PKPA` / `SUCT_HLT` 实时状态
7. **2BLD6010 遥测**：`SERIAL8_PROTOCOL=51`、`SERIAL8_BAUD=115`，按实机数量和 Modbus 地址设置 `BESC_*` 后重启

## 二、SERVO 输出（FUNCTION）

| 功能 | 当前通道 | `SERVOx_FUNCTION` | 说明 |
|------|----------|-------------------|------|
| 左履带 | SERVO3 | **73** | ThrottleLeft；PE13 / PWM(3)；`SERVO3_REVERSED=1` |
| 右履带 | SERVO4 | **74** | ThrottleRight；PE14 / PWM(4) |
| 前滚刷 | SERVO9 | **157** | VGSolarBrushFront；PC8 / PWM(9) |
| 后滚刷 | SERVO6 | **158** | VGSolarBrushRear；PD15 / PWM(6) |
| 吸盘升降 | SERVO5 | **159** | VGSolarSuctionLift |

`SERVO1/2/7/8_FUNCTION=-1`：对应的 PWM(1/2/7/8) 资源作为左右轮编码器 GPIO 输入，不作为执行机构输出。编码器固定映射为左轮 `WENC_PINA/B=56/57`，右轮 `WENC2_PINA/B=51/50`。CPR、轮径和安装位置属于实机标定，不写入板级默认参数。

左履带的电机接线方向为项目固定配置：`SERVO3_REVERSED=1`。升降舵机端点、其余输出反向、编码器 CPR、轮径和安装位置仍属于实机配置，不写入板级默认参数。

滚刷由 NCU 经 `AP_CompanionComputer` 写功率；电调约定 **1000 µs=停 / 2000 µs=满速**。  
升降目标 PWM 由 `SCUP_LIFT_PWM_R` / `SCUP_LIFT_PWM_L` 决定，并按 `SCUP_LIFT_RATE` 缓变。

旧版气阀/气泵 PWM（FUNCTION **160/161**）已废弃，勿再占用。

## 三、气阀 / 气泵（Relay）

| 参数 | 推荐值 | 含义 |
|------|--------|------|
| `RELAY1_FUNCTION` | **1** | Relay |
| `RELAY1_PIN` | **59** | 气阀 GPIO（PE5） |
| `RELAY1_INVERTED` | **1** | 气阀低有效；逻辑 ON 输出低电平 |
| `RELAY1_DEFAULT` | **0** | 上电默认关 |
| `RELAY2_FUNCTION` | **1** | Relay |
| `RELAY2_PIN` | **60** | 气泵 GPIO（PE6） |
| `RELAY2_DEFAULT` | **0** | 上电默认关 |
| `SCUP_VLV_RLY` | **0** | 吸盘库使用 RELAY1 |
| `SCUP_PUMP_RLY` | **1** | 吸盘库使用 RELAY2 |

逻辑：Relay **ON** = 阀密封 / 泵开；**OFF** = 放气 / 泵关。当前气阀使用 `RELAY1_INVERTED=1`，因此逻辑 ON 时 GPIO59 为低电平、逻辑 OFF 时为高电平；气泵保持非反相。

| 用途 | 参数 | 推荐值 |
|------|------|--------|
| 数传 | `SERIAL2_PROTOCOL` | **2**（MAVLink2） |
| 遥控器 | `SERIAL1_PROTOCOL` | **23** |
| 超声波 1 | `SERIAL4_PROTOCOL` / `SERIAL4_BAUD` | **9** / **9**（9600） |
| 超声波 2 | `SERIAL5_PROTOCOL` / `SERIAL5_BAUD` | **9** / **9** |
| **RK3588 / NCU** | `SERIAL6_PROTOCOL` / `SERIAL6_BAUD` | **50** / **115**（115200） |
| GPS | `SERIAL7_PROTOCOL` | **5** |
| 2BLD6010 电调遥测 | `SERIAL8_PROTOCOL` / `SERIAL8_BAUD` | **51** / **115**（115200） |

| 参数 | 项目基线 | 含义 |
|------|------|------|
| `CC_ENABLE` | **1** | 启用伴生电脑协议 |
| `CC_PORT` | **0** | 第 N 个「协议 50」串口实例（仅配 SERIAL6 时为 0） |

## 五、超声波测距（DYP-A02）

状态帧顺序：`LEFT_OUT → LEFT_IN → RIGHT_IN → RIGHT_OUT`（cm），无效 **`0xFFFF`**。  
四路在车头；板载两路串口接 **LEFT_OUT / RIGHT_OUT**，内侧两路由 FCU 同侧拷贝。  
安全带急停见 `VGS_RF_MAX`（仅查外两路；距离 > 上限或无效约 100 ms 后进 ESTOP，需 NCU 解除）。

| 参数 | 推荐值 | 含义 |
|------|--------|------|
| `SERIALx_PROTOCOL` | **9** | Rangefinder |
| `SERIALx_BAUD` | **9** | 9600 |
| LEFT_OUT | `RNGFND4_*` | UART8 对应量程计实例 4 |
| RIGHT_OUT | `RNGFND8_*` | USART2 对应量程计实例 8 |
| `RNGFND4_TYPE` / `RNGFND8_TYPE` | **45** / **45** | DYP-A02 |
| `RNGFND4_MIN_CM` / `RNGFND4_MAX_CM` | **3** / **450** | LEFT_OUT 量程 cm |
| `RNGFND8_MIN_CM` / `RNGFND8_MAX_CM` | **3** / **450** | RIGHT_OUT 量程 cm |
| `RNGFND4_ORIENT` / `RNGFND8_ORIENT` | **7** / **1** | LEFT_OUT / RIGHT_OUT；仅两路真传感器 |

```text
SERIALx_PROTOCOL = 9
SERIALx_BAUD = 9

RNGFND4_TYPE = 45
RNGFND4_ORIENT = 7   # LEFT_OUT
RNGFND4_MIN_CM = 3
RNGFND4_MAX_CM = 450

RNGFND8_TYPE = 45
RNGFND8_ORIENT = 1   # RIGHT_OUT
RNGFND8_MIN_CM = 3
RNGFND8_MAX_CM = 450
```

## 六、主电池与电量百分比（`BATT_`）

主电池通过 PC4（模拟引脚 4）采集电压、PA4（模拟引脚 18）采集电流。剩余电量百分比按 6S 电池包电压线性计算；电压和电流读数仍会正常上报。

| 参数 | 项目基线 | 含义 |
|------|------|------|
| `BATT_MONITOR` | **4** | 模拟电压和电流监视器 |
| `BATT_VOLT_PIN` | **4** | PC4 电压采样引脚，由板级 hwdef 固定 |
| `BATT_CURR_PIN` | **18** | PA4 电流采样引脚，由板级 hwdef 固定 |
| `BATT_CAPACITY` | **4000** | 标称容量 mAh；不再作为百分比计算依据 |
| `BATT_LOW_VOLT` / `BATT_CRT_VOLT` | **21.6** / **21.0** | 6S 低电压和严重低电压告警阈值 V |
| `BATT_VOLT_MULT` | **20.65** | 项目电压采样倍率 |
| `BATT_AMP_PERVLT` | **85** | 项目电流采样倍率 A/V |
| `BATT_AMP_OFFSET` | **-0.001** | 项目电流零点偏移 A |
| `BATT_PCT_SRC` | **1** | 1=按电压计算剩余百分比 |
| `BATT_PCT_VMAX` / `BATT_PCT_VMIN` | **25.2** / **19.8** | 6S 100% / 0% 电压 V，计算结果限幅到 0%~100% |
| `BATT2_CURR_PIN` | **-1** | PC0 已给吸盘压力传感器，不能作第二路电流输入 |

## 八、吸盘参数（`SCUP_`）

| 参数 | 项目基线 | 范围 | 含义 |
|------|------|------|------|
| `SCUP_LIFT_DLY_MS` | **2000** | 0~5000 | 无红外：PWM 到位后等待；有红外抬起：见铁片后补行程 |
| `SCUP_VAC_DLY_MS` | **10000** | 100~10000 | 启用压力传感器时为负压建立最大等待；禁用时为旧固定等待 |
| `SCUP_VENT_DLY_MS` | **2000** | 100~5000 | 放气后、抬起前等待 |
| `SCUP_ACT_TOUT_MS` | **30000** | 1000~60000 | lower/raise 整段超时 → FAULT |
| `SCUP_LIFT_PWM_R` | **1900** | 1000~2000 | 抬起位置 PWM µs |
| `SCUP_LIFT_PWM_L` | **1100** | 1000~2000 | 放下位置 PWM µs |
| `SCUP_LIFT_RATE` | **400** | 50~5000 | 升降缓变 µs/s（默认约 2 s 走完 800 µs） |
| `SCUP_VLV_RLY` | **0** | 0~5 | 气阀 Relay 实例 |
| `SCUP_PUMP_RLY` | **1** | 0~5 | 气泵 Relay 实例 |
| `SCUP_IR_PIN` | **98** | ≥0 或 -1 | 槽型光电 GPIO；**-1=禁用红外** |
| `SCUP_IR_POL` | **0** | 0/1 | 0：高=有铁片、低=完全放下；1：反相 |
| `SCUP_IR_DEB_MS` | **30** | 0~500 | 红外消抖 ms |
| `SCUP_LIFT_TO_MS` | **5000** | 500~15000 | 有红外时等放下/见铁片超时 → FAULT |
| `SCUP_VAC_P_KPA` | **-70** | -100~0 | 压力连续低于或等于该值后判定吸附建立，单位 kPa |
| `SCUP_VAC_DEB_MS` | **300** | 0~2000 | 压力达标和吸附后掉压的连续消抖时间 ms |
| `SCUP_VAC_HYST` | **5** | 0~50 | 掉压阈值回差；压力高于 `VAC_P_KPA + VAC_HYST` 时开始掉压计时，单位 kPa |

**到位逻辑摘要**

- 有红外：放下 = 缓速中可记「见过铁片」，PWM 到位后再等「无铁片」；抬起 = 见铁片 + `LIFT_DLY`，且 PWM 到位。  
- 无红外（`IR_PIN=-1`）：PWM 到位后再等 `LIFT_DLY`。  
- `SPRESS_PIN=10`：开泵后压力必须连续 `VAC_DEB_MS` 小于等于 `VAC_P_KPA` 才进入 `LOWERED`；压力不健康时不会回退固定延时。
- `SPRESS_PIN=-1`：禁用压力判断，保持原 `VAC_DLY_MS` 固定等待逻辑。
- 启用压力判断但在 `VAC_DLY_MS` 内未达标：停泵、放气并进入 `FAULT`。
- 已进入 `LOWERED`/有效 `FROZEN` 后持续掉压只告警，不自动放气、不置 `FAULT`、不中止转弯。
- 已保存旧参数的飞控不会自动改升降默认值，需手动设 `LIFT_PWM_R/L` 或重置相关参数。

## 九、吸盘压力参数（`SPRESS_`）

VGSolar 使用 MCP-H10-B100KPN-P（MCP-H10-P）3.3V 负压表压模块，PC0 对应 ArduPilot ADC 逻辑引脚 `10`。默认标定关系为：0.1V=0kPa、1.6V=-50kPa、3.1V=-100kPa。

| 参数 | VGSolar 默认 | 范围 | 含义 |
|------|--------------|------|------|
| `SPRESS_PIN` | **10** | ≥0 或 -1 | PC0 压力 ADC；**-1=禁用压力模块并启用吸盘旧固定延时逻辑** |
| `SPRESS_V_MIN` | **0.1** | 0~3.3 | 对应 `SPRESS_P_MIN=0kPa` 的传感器电压 V |
| `SPRESS_V_MAX` | **3.1** | 0~3.3 | 对应 `SPRESS_P_MAX=-100kPa` 的传感器电压 V |
| `SPRESS_P_MIN` | **0** | -150~0 | `V_MIN` 对应压力 kPa |
| `SPRESS_P_MAX` | **-100** | -100~50 | `V_MAX` 对应压力 kPa |
| `SPRESS_FILT_HZ` | **5** | 0.1~20 | 压力一阶低通滤波截止频率 Hz |

压力模块以 50Hz 采样。连续有效约 100ms 后健康；连续无效约 200ms 后报告异常；超过 250ms 未更新时报告过期。R95 不安装后，软件不能可靠识别所有传感器开路情况。

升级时，如果压力模块启用且四项保存值仍完全等于旧 XGZP 默认值 `0.2/2.7/-100/0`，固件会自动迁移到 `0.1/3.1/0/-100` 并发送一次 `MCP-H10 pressure calibration migrated`。用户自定义过任一标定端点时不会覆盖。

### Mission Planner 实时查看

1. 确保 `RAW_SENS` 或当前链路的 `SRx_RAW_SENS` 至少为 1Hz。
2. 连接飞控后打开 **Flight Data -> Status**。
3. 搜索 `press_abs2`，确认标准 `SCALED_PRESSURE2.press_abs` 字段持续更新。
4. 搜索 `SUCT`，查看兼容健康字段：

| 字段 | 含义 |
|------|------|
| `SUCT_PKPA` | 当前滤波后的吸盘压力，单位 kPa；无健康数据时为 NaN |
| `SUCT_HLT` | 压力健康标志：1=健康，0=禁用、预热、无效、无源或过期 |
| `press_abs2` | VGSolar 吸盘压力，单位 hPa；数值为 `SUCT_PKPA*10`，无健康数据时为 NaN |

DataFlash 中对应日志消息为 `SPRS`，字段为 `TimeUS,Volt,Press,Health,Status`，约 10Hz 记录。

VGSolar 上 `press_abs2` 不表示第二个大气压力传感器。第一个 BMP388 仍通过 `SCALED_PRESSURE` 输出；两个 BMP388 仍可由 `AP_Baro` 内部读取，但第二个 BMP388 不再通过 `SCALED_PRESSURE2` 对外发送。非 VGSolar 板保持原有第二气压计遥测行为。

## 十、2BLD6010 电调遥测参数（`BESC_`）

驱动在同一条 RS485 总线上按固定顺序轮询最多 4 台 2BLD6010。协议为 Modbus RTU 功能码 `0x03`，只读寄存器 `0x0020~0x0027`；每台电调发布温度、电压、电流和 RPM 到标准 `AP_ESC_Telem`，同时保留方向、故障码、霍尔计数和通信统计供诊断。

| 参数 | 代码默认 | 范围 | 含义 |
|------|------|------|------|
| `BESC_ENABLE` | **0** | 0/1 | 启用 2BLD6010 遥测；修改后重启 |
| `BESC_NUM` | **1** | 1~4 | RS485 总线上参与轮询的电调数量 |
| `BESC_ADDR1` | **2** | 1~247 | 第 1 个参数槽位的 Modbus 地址 |
| `BESC_ADDR2` | **1** | 1~247 | 第 2 个参数槽位的 Modbus 地址 |
| `BESC_ADDR3` | **3** | 1~247 | 第 3 个参数槽位的 Modbus 地址 |
| `BESC_ADDR4` | **4** | 1~247 | 第 4 个参数槽位的 Modbus 地址 |
| `BESC_OFS` | **0** | 0~31 | 第一个标准 ESC 遥测实例索引；`ADDRn` 映射到 `OFS+n-1` |
| `BESC_RATE` | **10** | 1~20 Hz | 每台电调的目标轮询频率；实际频率受 100Hz 调度、响应时间和离线超时影响 |
| `BESC_TIMEOUT` | **500** | 100~5000 ms | 最近合法遥测超过该时间后判为不健康；单次 Modbus 响应超时固定为 40ms |

启用时会一次性校验全部参数：`ENABLE` 必须为 0/1，`NUM` 必须为 1~4，启用范围内的地址必须为 1~247 且互不重复，`OFS+NUM` 必须落在标准 ESC 实例范围内。任一项非法时驱动整体不启动，并向地面站发送 `2BLD6010: invalid config (N)`；错误编号依次对应非法使能、数量、地址、重复地址、偏移、实例越界、频率和健康超时。

当前项目默认启用四台 2BLD6010 遥测：`BESC_ENABLE=1`、`BESC_NUM=4`，Modbus 地址按 `2/1/3/4` 轮询，`BESC_OFS=0`、`BESC_RATE=10`、`BESC_TIMEOUT=500`。此功能只读取遥测，不改变履带和滚刷的 PWM 控制。

### Mission Planner 与日志查看

1. 写入 `SERIAL8_*` 和 `BESC_*` 参数后重启飞控。
2. 在 Mission Planner 的 MAVLink Inspector 中查看 `ESC_TELEMETRY_1_TO_4`；`BESC_OFS=0` 时前四个字段依次对应 `BESC_ADDR1~4`。
3. 下载 DataFlash 日志，查看标准 `ESC` 消息中的 `RPM/Volt/Curr/Temp`。
4. 查看自定义 `BESC` 通信诊断消息：`TimeUS,Inst,Addr,Healthy,Dir,Fault,Hall,Success,CRCErr,Timeout,BadResp,Except`。

`BESC` 中 `Inst` 是从 0 开始的本驱动槽位，`Addr` 才是 Modbus 地址。`Fault` 是设备原始故障码；当前代码不会把它自动写入 VGSolar 的 NCU `fault_code`，也不会自动停车或关闭滚刷。

CC_LOG = 1

SERIAL6_BAUD = 115
